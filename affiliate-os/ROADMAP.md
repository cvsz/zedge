# Roadmap

0. Discovery and architecture: **written** (this folder)
1. Foundation: link service **done**; contracts, Postgres, auth, events, adapter interface, studio shell, observability: planned
2. Affiliate core: providers, products, offers, links, campaigns, conversions, commissions
3. Content studio: planner, copy, images, video, asset library, templates
4. Publishing: adapters (after capability verification), scheduler, calendar
5. Analytics: attribution, dashboards, reports
6. Intelligence: scoring, trends, recommendations
7. Automation: approval workflows, autonomous policies
8. Optimization: experiments, learning loops
9. Hardening: security review, load tests, backup/restore, DR, SLOs, runbooks, cost controls
Order and scope are decided in `exec-planning.md`; this file states direction only.
